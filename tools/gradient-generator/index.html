Frequently Asked Questions

Why do standard CSS gradients turn muddy gray in the middle?

In sRGB, opposite colors like royal blue and warm orange cancel each other’s red, green, and blue channels at 50%, collapsing into a dull gray. Switching to OKLCH Vivid interpolates hue polar coordinates while maintaining perceptual lightness and saturation.

Does the exported CSS work in older browsers?

Yes. Clicking COPY CSS bakes high-precision perceptual color stops directly into standard HEX linear-gradient() syntax so every browser displays the exact same smooth curve.
